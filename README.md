## 🚀 Proyectos destacados

### 📦 BackupMonitor
Herramienta desarrollada en PowerShell para automatizar la verificación de respaldos, identificar archivos faltantes o desactualizados y generar reportes de estado.

**Tecnologías:** PowerShell, JSON, CSV, SHA-256.

🔗 [Ver repositorio](https://github.com/Sebascrojas20/BackupMonitor)

### 📊 ServerHealth-Monitor
Solución de monitoreo para servidores Windows que recopila información sobre recursos del sistema, servicios y conectividad. Incluye un dashboard desarrollado con Streamlit para visualizar resultados y consultar reportes históricos.

**Tecnologías:** PowerShell, Python, Streamlit, Pandas y Plotly.

🔗 [Ver repositorio](https://github.com/Sebascrojas20/ServerHealth-Monitor)
